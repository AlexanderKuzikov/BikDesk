# BikDesk — DECISIONS

<!-- Append-only. Формат фиксирован. -->

## 2026-09-07: Отдельный сервис, не часть CaseCore

**Контекст:** Справочник нужен нескольким приложениям, не только витрине CaseCore.

**Решение:** Отдельный репозиторий, отдельный сервис, отдельная БД `banks` в существующем PG-кластере Sat. CaseCore — обычный HTTP-клиент без привилегий.

**Альтернативы:** Вшить таблицы и ручки в CaseCore (один деплой, reuse TS-стека).

**Trade-off:** +1 сервис в оперейшн; зато релизный цикл витрины не роняет справочник всем потребителям.

## 2026-09-07: Python для всего v1

**Контекст:** Ночной разбор ED807-XML + тонкий read API.

**Решение:** Python на стандартной библиотеке (urllib, zipfile, xml.etree, http.server). На Sat уже стоит 3.12.

**Альтернативы:** Node (нет XML-парсера и распаковки zip в stdlib — минимум 3 зависимости), Go (идеальный одиночный бинарь, но ставить тулчейн ради джоба на ~1400 строк — избыточно).

**Trade-off:** PG-драйвер — единственная внешняя зависимость; без него синк пишет только JSONL.

## 2026-09-07: JSONL-снапшот + PG, сырые коды ЦБ

**Контекст:** Нужны реквизиты для платёжек (критичен корсчёт) и шапок запросов о счетах, плюс дифф в git.

**Решение:** `banks.jsonl` (строка на БИК, сортировка) + `banks.meta.json` как артефакт синка; PG-таблицы `banks` + append-only `bank_changes`. Коды PtType/ParticipantStatus/AccountStatus храним как есть, маппинги — после сверки с альбомом УФЭБС.

**Альтернативы:** Один большой banks.json (каша в диффе), SQLite (лишний при живом PG-кластере), интерпретация статусов по догадкам.

**Trade-off:** Двойная запись (файл + БД) до включения PG-апдейта по умолчанию.

## 2026-09-07: PostgreSQL 18, не 19

**Контекст:** Пользователь предположил, что последняя стабильная выше 18.

**Решение:** `postgres:18-alpine` (18.6). Проверено на сайте PG: 19 на сентябрь 2026 только Beta 3, релиз осенью. Совпадает с кластером Sat (там уже 18.6) — отдельная БД `banks` без новых контейнеров.

**Альтернативы:** Ждать 19, ставить бету.

**Trade-off:** Никаких — бету в прод не тянем.

## 2026-09-07: Фронт без сборки, раздаёт сам API

**Контекст:** Нужен удобный просмотр и сортировка банков на сервере.

**Решение:** Один `web/index.html` на ванильном JS (поиск + сортировка по клику на заголовок), отдаёт сам `api.py` на `/`. Caddy — один reverse_proxy без file_server. Ноль зависимостей, ноль сборки.

**Альтернативы:** Отдельный фронт на Node/Vite, Caddy file_server.

**Trade-off:** Симпатичнее не станет без фреймворка; для таблицы на 1400 строк хватает за глаза.

## 2026-09-07: Порт 8790, без auth

**Контекст:** На Sat 8788 занят SerpGladys, 8789 — StatGladys. Оба закрыты Bearer-ключом, CORS — в Caddy.

**Решение:** BikDesk на 8790, отдельный поддомен без path-handle в главном блоке. Auth нет: данные ЦБ публичные, API только читает. CORS-заголовки не ставим — фронт ходит same-origin, серверные потребители в CORS не нуждаются.

**Альтернативы:** Path-handle в главном блоке + поддомен (как у Gladys), Bearer-ключ «для единообразия».

**Trade-off:** Ключ добавим, когда появится хоть одна непубличная ручка; пока это лишний секрет в оперейшн.

## 2026-09-07: PG-апдейт при SKIP + venv на Sat

**Контекст:** Первый запуск на Sat: JSONL записался, PG упал на пароле — повторный прогон ушёл в SKIP и БД осталась пустой.

**Решение:** PG-апдейт выполняется всегда, включая SKIP-ветку (идемпотентный). Рантайм синка — venv с psycopg, DSN только из `.env` (600), в юнитах `EnvironmentFile`, в репо `.env` в игноре.

**Альтернативы:** Только --force для ручной догонки.

**Trade-off:** Лишний diff-запрос к PG каждую ночь; зато БД самовосстанавливается.

## 2026-09-08: Полигон без входа

**Контекст:** Соло-полигон на домашней машине: пароль и форма входа — налог без пользы.

**Решение:** В копии echo/ вход отключён целиком: сервер считает каждый запрос первым админом (при пустой базе создаёт его сам), в клиенте нет формы входа и кнопки выхода. Апстрим-шаблон не тронут — там вход живёт дальше, копии разошлись осознанно.

**Альтернативы:** Автовход с локалки (форме входа всё равно показывалась без сессии); снос входа в апстриме (портит публичный шаблон).

**Trade-off:** Копия echo/ расходится с апстримом; такую копию на публику выкатывать нельзя без ограничений на стороне Caddy.
