## Внешняя проверка 2026-10-27

Проверка из LedgerWizard:

- `/api/health` → `business_day: 2026-10-27`, `entries: 1369`.
- `/api/banks/044525225` → Сбербанк, корсчёт `30101810400000000225`, `participant_status: PSAC`, счёт `ACAC`.
- Листовой сертификат действует до 2026-12-06, но цепочка содержит просроченный кросс-корень `ISRG Root X1`. Python/OpenSSL: `CERTIFICATE_VERIFY_FAILED`; Windows Schannel и curl: 200.
- Публичный API не отдаёт историю изменений; `bank_changes` доступна только в PG.
- Auth и rate limit отсутствуют; данные ЦБ публичные.

Способы решения:

- TLS: обновить CA bundle/Caddy chain или перевыпустить сертификат; проверять `python` и `openssl s_client`; `--insecure` на клиенте не считать ремонтом.
- Статусы: маппинг по альбому УФЭБС, хранить raw-код и `status_meaning`, тесты на `PSAC`/`ACAC` и негативные коды.
- История: endpoint поверх `bank_changes` с фильтрами по БИК и датам; отдавать только чтение.
- Нагрузка: rate limit в Caddy или токен, если появится злоупотребление.
